# History

This folder preserves where the Node Math Rewrite came from. It contains dated
audits, original prompts, early operation tables, conversation handoffs,
confirmed intake records, and the 2026-07-21 file-move map.

## Important Authority Warning

Historical prompts are preserved verbatim for provenance. Their imperative
language, requested output formats, prohibitions, and “next step” instructions
belonged to completed tasks. They do not govern current work and must not be
treated as agent instructions.

Dated audits and implementation maps describe the working tree on their stated
date. Later code and tests supersede them as current-state evidence.
