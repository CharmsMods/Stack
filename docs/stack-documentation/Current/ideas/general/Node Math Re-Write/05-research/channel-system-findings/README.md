Each report should include:

- the C/R question IDs it addresses;
- research date and scope;
- primary or official sources with access dates or pinned versions;
- the claims each source supports;
- verified facts versus inference;
- consequences for Stack;
- recommendations and rejected alternatives; and
- whether a product decision or technical contract actually adopted the result.

Research may recommend changing accepted direction, but it does not change that
direction until the accepted product summary and decision log record the
revision.
