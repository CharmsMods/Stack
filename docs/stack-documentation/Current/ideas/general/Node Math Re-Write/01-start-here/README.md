# Start Here

This is the plain-language entrance to the Node Math Rewrite. You do not need
to memorize the technical documentation before talking about the product.

Read whichever file matches what you want to do:

- [What We Are Building](what-we-are-building.md) explains the goal and the
  non-negotiable user experience in ordinary language.
- [Current Status](current-status.md) says what is done, what is only designed,
  and what could happen next.
- [Questions For You](questions-for-you.md) gives you an answer sheet for the
  choices that still need review.
- [Decision Log](decision-log.md) is the precise record when you want the full
  technical wording and decision IDs.

You can add notes or answers in plain language. When a choice becomes accepted,
an agent should translate it into the appropriate design or technical file,
record the decision, and keep this plain-language layer readable.
