# UI Parameter Debug Menu And Figma Handoff

- Captured: 2026-07-03 01:33
- Source: docs/stack-documentation/Archived/source-notes/2026/2026-07-03-0133-slice-video-graph-notes.md
- Type: idea
- Topic: editor
- Verification: unverified

We likely need a settings/debug menu that lets UI parameters be adjusted while features are being built. That would let implementation work and visual tuning happen together instead of hard-coding styling decisions too early.

Once a parameter set feels right, the chosen values can be reflected in the Figma file Adrian reads so they become the stable design target.

## Follow-Up

- Decide whether this menu is editor-only, app-wide, or limited to developer builds.
- Identify which parameters should be live-tunable first, such as spacing, radius, stroke, contrast, motion, or inspector sizing.
- Decide how approved values move from the debug menu into permanent UI tokens or constants.
