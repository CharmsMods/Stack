# Checkpoint Authorization Request

This is a record/template, not proof of permission.

Stack needs written confirmation from the checkpoint rights holder that Stack
may:

1. use the official Real Image Denoising and Gaussian Color Blind Restormer
   checkpoints in a commercial proprietary application;
2. convert those checkpoints from their published PyTorch form to FP32 ONNX;
3. redistribute the original or converted weights inside a separately
   downloadable optional package;
4. sign, hash, mirror, update, and remove that package through Stack's Package
   Manager;
5. permit end users to run the models locally/offline on their photographs;
6. include the required attribution, license, and notice files without
   disclosing Stack's proprietary source.

The response must identify the exact checkpoint files or hashes and the person
or entity authorized to grant these rights. Silence, a repository MIT license,
or a public download link is not sufficient for Stack's release gate.

Until this record contains the written grant and reviewed artifact hashes,
`authorizationStatus` must remain `development-only`.
