## Original Text

Okay, it has taken me a long time to learn this and finally come to this conclusion. But after a lot of trial and error and it not working out multiple times, I think I want to archive Stack's current goal of trying to have an automatic raw editor that can perform its own edits. Instead, I want to try to import the image in as transparent and truthful as I can, as possible. I want to really redesign the user interface (UI) to be less of a crazy long scroll list with a bunch of dropdowns and more of something that incorporates windows and the graphs we have for the local exposure and the tone mapping. I just want to make this a lot more manual instead of trying to make everything automatic and being lazy. I think we need to start by archiving the parts of the UI that have anything to do with the automatic mode. After that, we can start building out our workflow for editing a raw image from the ground up.
