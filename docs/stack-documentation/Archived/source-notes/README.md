# Source Notes Archive

This folder preserves original note dumps that users hand to the agent for
sorting.

## Rules

- Store direct pasted text here as the source record before routing it into
  working docs.
- Create year subfolders as needed, for example `2026/`.
- Use the filename format
  `YYYY-MM-DD-HHMM-<short-session-title>.md`.
- If the source is a long pasted note or an attached document outside the repo,
  ask the user to place the original file here manually instead of recreating
  it from memory.
- These files are preserved source records, not the main working destination.
