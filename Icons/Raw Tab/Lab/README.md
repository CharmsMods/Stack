# RAW Lab icon intake

Place optional RAW Lab icons in this folder using the filenames below.
The executable falls back to text while an icon is absent.

All artwork should be a transparent 256 x 256 PNG with centered, container-free
line art and no embedded text.

```text
raw-lab.png
light.png
zones.png
save.png
reset.png
target.png
filmstrip.png
workspace-gallery.png
final-view.png
compare.png
affected.png
delta.png
highlight-risk.png
inspect.png
fit-view.png
```
