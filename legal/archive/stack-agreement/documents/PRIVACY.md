# Stack Privacy Notice

Version 1.0-draft  
Effective date: August 6, 2026

> **Draft — attorney review required. Not approved for public release.**

Stack is an image editor published by Darynn Ho under the Stack, Charm, and
CharmsMods brands. You do not need an account, activation, payment, or contact
with the publisher to use an official Stack release.

## What Stack sends

The current desktop application does not include intentional product analytics,
advertising trackers, crash-report uploads, or a Stack-operated telemetry
service.

By default, Stack makes an HTTPS request to the GitHub releases API after the
EULA has been accepted and when at least twelve hours have passed since the last
automatic check. The request asks for information about the latest official
release. GitHub may receive ordinary connection data such as your IP address,
request time, and user agent under GitHub's own privacy terms.

You may turn off **Check automatically when Stack starts** in Stack Settings.
Manual update checks and update downloads contact GitHub only when you request
them. Opening a Stack website or release link uses your default web browser.

## What Stack stores locally

Stack stores settings, update state, projects, presets, library information,
cached downloads, logs, and temporary working files on your computer. Installed
copies normally use your Windows AppData folders. Portable copies normally use
the `Stack/User` and `Stack/Temp` folders beside the portable executable.

The legal-acceptance record stores only the EULA version and hash, privacy
version, acceptance time, and whether acceptance occurred through the installer
or portable application. It does not contain a Stack account or contact details.

Stack does not automatically upload your images, projects, presets, local file
paths, or local logs to Darynn Ho or CharmsMods.

## Stack website

The Stack website may request public release information from GitHub's API so it
can display or link to the current download. GitHub receives ordinary network
information for that request. Website font files are hosted with the Stack site;
the website does not contact Google Fonts.

The current website does not intentionally use Stack-operated analytics,
advertising cookies, user accounts, or contact forms. The hosting provider may
process routine server or security logs under its own terms.

## Third-party services

GitHub hosts Stack's repository, releases, issue tracker, and website. When you
use those services, GitHub's own terms and privacy notice apply. Links to other
services are governed by those services' policies.

## Retention and control

Local data remains on your computer until you delete it, Stack removes a cache
as part of normal operation, or you choose to remove it during uninstall. You
can preserve user data when uninstalling Stack. GitHub controls retention of
data that GitHub receives.

## Changes

This notice is versioned. A release validator checks that the notice shipped
with a public build matches an approved hash. Material application or website
network changes must update this notice before public packaging can proceed.

## Questions

Ordinary questions may be submitted through the official Stack repository's
GitHub Issues page. Security vulnerabilities should use GitHub's private
vulnerability-reporting feature. No contact is required to use Stack.
