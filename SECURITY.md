# Security Policy

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** feature on the Security tab of the
official Stack repository. This creates a private report visible to the
repository owner and avoids exposing users before a fix is available.

Please include the affected Stack version, impact, reproduction steps, and any
suggested mitigation. Do not include private images, projects, credentials, or
unrelated personal data.

If GitHub's private reporting feature is temporarily unavailable, contact the
official repository owner through the contact method shown on the owner profile.
Do not file a public issue containing exploit details.

## Supported versions

Stack is currently alpha software. Security fixes are normally applied only to
the latest official release. Older versions may stop receiving fixes without
notice.

## Scope

Good-faith reports are welcome. This policy does not grant permission to access
another person's data, disrupt services, distribute Stack source or modified
binaries, or violate the Stack license or applicable law.
